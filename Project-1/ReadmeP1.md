# Data Cleaning Project using Python & Pandas

This project focuses on cleaning and preprocessing raw data using Python and Pandas. The dataset contained missing values, duplicate records, inconsistent text formatting, and incorrect date formats. The project includes handling missing values, removing duplicates, formatting dates, converting data types, cleaning text columns, and exporting the cleaned dataset into a new Excel file.

## Features
- Checked dataset information
- Identified and handled missing values
- Filled missing coupon codes
- Removed duplicate records
- Standardized date formatting
- Converted numeric columns into correct data types
- Cleaned text columns by removing extra spaces
- Exported cleaned dataset to a new Excel file

## Technologies Used
- Python
- Pandas
- Excel

## Output
The cleaned dataset is exported as:
`Cleaned_Dataset.xlsx`
