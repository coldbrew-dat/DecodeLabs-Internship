# SQL Data Analysis Project

## Overview
This project was completed as part of a Data Analytics Internship task. The objective of the project was to analyze a sales dataset using SQL queries and extract useful business insights from the data.

The dataset was imported into PostgreSQL from a cleaned CSV file and analyzed using different SQL operations such as filtering, sorting, grouping, and aggregation.

---

## Objectives
- Perform data analysis using SQL
- Retrieve specific records using queries
- Filter and sort data
- Analyze grouped data
- Generate insights using aggregate functions

---

## Tools Used
- PostgreSQL
- pgAdmin
- SQL
- VS Code

---

## SQL Concepts Used
- SELECT
- WHERE
- ORDER BY
- GROUP BY
- COUNT()
- SUM()
- AVG()
- HAVING

---

## Analysis Performed
- Retrieved complete dataset records
- Filtered products based on conditions
- Sorted sales data by total price
- Calculated total orders
- Calculated total revenue
- Calculated average sales amount
- Analyzed revenue by payment method
- Compared product revenues
- Evaluated order statuses
- Analyzed average spending by referral sources
- Identified highest revenue-generating products

---

## Key Insights
- Certain products generated significantly higher revenue than others
- Payment methods showed different revenue contributions
- Order statuses helped identify completed and pending orders
- Average customer spending varied across referral sources
- Product quantity analysis revealed top-selling items
