# Project 4 — E-Commerce Data Visualization

Analyzing **1,200 e-commerce orders** to uncover insights about sales, customer behavior, and product trends.

> **Note:** Dashboard was built using Python (Tkinter + Matplotlib). Visualizations are also showcased as a PowerPoint presentation.

---

## What's Inside

| File | Description |
|------|-------------|
| `ECommerce_Dashboard.pptx` | 5-slide professional dashboard presentation |
| `dashboard.py` | Python + Tkinter + Matplotlib interactive dashboard |
| `Cleaned_Dataset.xlsx` | Dataset with 1,200 orders across 14 columns |

---

## Dashboard Preview

**Slide 1** — KPI Summary (Total Orders, Revenue, Avg Order Value)

**Slide 2** — Order Status breakdown + Revenue by Product

**Slide 3** — Payment Methods + Referral Sources

**Slide 4** — Product Order Volume across 7 categories

**Slide 5** — Key Business Insights

---

## Key Findings

- Over **42% of orders** were cancelled or returned
- **Chair & Printer** topped revenue at ~$195K each
- **Instagram** was the #1 customer acquisition channel
- **Online payment** was the most used method
